# Stationeers Path Patch

When running Stationeers on OSX using CodeWeavers CrossOver, the game fails to delete the temp folder used to unzip save files, causing the load to fail. This mod catches that error and allows loading to continue, optionally printing the error to the in-game console.


This requires an installed mod loader to run. See: https://github.com/StationeersLaunchPad/StationeersLaunchPad

Download `PathPatch.zip` from Releases and unzip into `%HOME%/Documents/my games/Stationeers/mods/`
